# COMP 664 Project 5 — Project Update

## Research question

Under matched paired data and training budgets, does frozen-feature late fusion
improve informative-post classification in-distribution and on a completely
held-out California Wildfires event?

## Data and leakage controls

- CrisisMMD v2.0 official agreed-label split: 12,708 paired examples.
- The released split has zero cross-split tweet/image IDs but 50 duplicated image
  contents across ID splits. The unchanged release is retained for provenance.
- Main experiments use explicitly named strict sensitivity manifests, removing
  duplicated content only from lower-priority splits and preserving every test row.
- ID strict: 9,535 / 1,570 / 1,534 train/validation/test examples.
- OOD strict: 9,808 / 1,665 / 1,195; California appears only in test.

## Models and setup

Frozen DistilBERT text encoder, frozen ImageNet ResNet-18 image encoder, and a
Late Fusion MLP over concatenated 768+512-dimensional features. Three seeds
(42, 123, 2026), AdamW, LR 1e-3, batch 64, maximum 25 epochs, patience 5, and
validation macro-F1 checkpoint selection.

## Current results (mean ± seed standard deviation)

| Protocol | Model | Accuracy | Macro-F1 |
|---|---|---:|---:|
| ID | Text-only | 0.8557 ± 0.0040 | 0.8360 ± 0.0032 |
| ID | Image-only | 0.8253 ± 0.0011 | 0.8013 ± 0.0025 |
| ID | Late Fusion | **0.8931 ± 0.0051** | **0.8794 ± 0.0052** |
| California OOD | Text-only | 0.7891 ± 0.0065 | 0.6735 ± 0.0027 |
| California OOD | Image-only | 0.7883 ± 0.0087 | 0.7260 ± 0.0078 |
| California OOD | Late Fusion | **0.8265 ± 0.0182** | **0.7577 ± 0.0167** |

Fusion improves the mean in both protocols. However, California OOD remains
substantially harder: Fusion's seen-validation-to-held-out macro-F1 gap is
0.1428 ± 0.0186; Text-only's gap is 0.1718 ± 0.0026.
